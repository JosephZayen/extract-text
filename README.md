# extract-text

this project parses cli inputs and extract text from given paths,
currently supports pdf, pptx

# usage

## cli install
```console
cd [project path]
pip install -e ./
```

## cli usage

extract-text [options] 
options:
-r to search recursively (input directories path)
otherwise only input file paths instead

```console
$ {
$ path,
$ path,
$ path
$ }
```
